A machine-learning application for speech clarity assessment and facial-expression-based pain detection for individuals with cerebral palsy.

## Problem

Individuals with cerebral palsy may experience difficulty with speech clarity and communicating discomfort.

## Solution

Built a dual ML workflow: MFCC+KNN for speech clarity and InceptionV3 for facial-expression pain detection.

## Highlights

- Speech clarity analysis using MFCC feature extraction and KNN classification
- Facial expression pain detection using InceptionV3 neural networks
- Full-stack web application connecting Next.js/TypeScript UI with FastAPI/Python ML backend
