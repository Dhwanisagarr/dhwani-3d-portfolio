An AI-powered fintech stack optimizer that helps users build and improve their financial app setup.

## Problem

With so many fintech apps available, beginners struggle to know which products actually fit their needs.

## Solution

Built an AI-driven stack recommendation engine analyzing user goals, detecting overlaps, and optimizing app setups.

## Highlights

- AI/LLM natural-language goal extraction and profile scoring engine
- Stack gap and overlap analysis across saving, investing, and spending
- Natural-language Stack Advisor with interactive app comparison
